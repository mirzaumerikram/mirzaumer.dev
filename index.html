06 / Insights

Things I have learned the hard way

Meta Ads

Your pixel is lying to the algorithm

Most underperforming ad accounts share one root cause: Event Match Quality so low the algorithm is optimizing blind. Fix the data before touching the creative.

From real client audits →
AI Agents

RAG beats fine-tuning for most business use cases

If the knowledge changes weekly, retrieval wins. Fine-tuning locks yesterday's answers into the weights. Every production agent I have shipped uses retrieval first.

From production builds →
Automation

The best automation keeps a human on the trigger

Full autopilot fails silently. Every workflow I build drafts the action and waits for approval before anything touches money, customers, or live campaigns.
